# Exported weights

Generated by `tools/export_to_matlab.py` from the Python checkpoints and
self-checked against PyTorch at export time. Do not edit by hand.

| file | contents |
|---|---|
| `segmentation.mat` / `segmentation_spec.json` | Attention U-Net, shared by both bundles |
| `pooled/` | grader trained on all four corpora pooled; the bundle `data/showcase` was selected with. The MATLAB default. |
| `prepool/` | grader trained on APTOS-2019 + IDRiD; Messidor-2 held out. The bundle behind the external-validation figures. |

Each bundle directory holds `grader.mat` (weights), `grader_spec.json`
(architecture) and `pipeline.json` (temperature, isotonic calibrator, referral
threshold, quality and triage settings). The launchers default to
`C.DEFAULT_BUNDLE` in `+drscreen/constants.m`. Any directory with the same
three files can be passed in place of a bundle name.

Regenerate after retraining, from the Python repository root:

    .venv/Scripts/python.exe convrt_matlab/tools/export_to_matlab.py
